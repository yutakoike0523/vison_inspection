# FFTピーク格子関係分析

## 方法

全画像に対し、グレースケール・平均除去・2次元Hann窓・2次元FFTを適用した。DC近傍4 binを除外し、中心対称な局所最大を1組として強度順に集約した。`fft_peak_pairs.csv` は各画像の上位30組だけであり、FFT-bin座標とcycles/pixelを併記している。

基本波候補は上位10組から選び、周期35 px以上、方向の独立性（共役を同一方向とみなして角度差20°以上）を満たす2組を総当たりした。各候補から `-4 <= m,n <= 4` の整数格子を予測し、実測上位30ピークとの距離が2 FFT-bin以下の対応だけをHungarian法で一対一に割り当てた。

順位scoreは一致ピークのdB強度を加点し、係数次数と座標誤差を減点した探索指標である。高次係数を多く許しただけで得られる偶然一致を格子由来と確定していない。従来の上位2組は `is_legacy_top2=true` として同じ表に残した。

## 読み方

- 青: 選択基本波
- 緑: 単一方向高調波
- 橙: 混合成分
- 赤: 上位30内で未説明のピーク
- 各対応の係数、予測・実測座標、bin誤差、突出度、強度は `peak_matching_results.csv` に記録した。

image18は428×321 pxであり、2 bin許容幅は他の画像よりcycles/pixel換算で大きい。このためimage18の一致数を2048×1536画像と同じ確度で比較してはならない。

## 結論の扱い

規則性順位が強度上位2組と一致しない画像があるため、強度だけで基本波を決めるのは不十分である。一方、低次整数格子で説明できないピークも残る。これらは照明、境界、札、傷、Hann窓による広がり、または局所的な格子周期変動に由来し得る。基本波・高調波の採用には、ここでの一対一対応に加え、逆FFTで格子を再現するか、複数位置で安定かを確認する必要がある。
