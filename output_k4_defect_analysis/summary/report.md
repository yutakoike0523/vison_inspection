# K=4 局所変形の検出・見逃し分析

256 px窓、stride16、参照間隔128 px、最大8候補、medoidと最近傍のK=4・5・8。元の放射FFT特徴量・保存済み選択結果・全有効地点LOIOを使用。候補3未満は無効。Kごとの閾値は画像を除いた正常画像から設定し、格子あり・なしを分けた。K=4は同じ画像群の先行比較から選んだ探索条件であり、独立した汎化性能ではない。

代表窓は各傷のK=4傷中心スコア最大点で、他のKも同じ座標の対象・参照スペクトルを比較。検出の成否はKごとに傷中心全地点の最大値で判定するため、代表点のスコアと別Kの傷中心最大値は一致しない場合がある。代表点選択により傷の平均的な状態を表すとは限らない。参照窓や画像範囲は強く重複する。明部・暗部・格子境界の信頼できる分類は実施せず全件未判定。

各周波数帯の寄与は対象と基準のdB差の二乗和を全ビンの二乗和で割った値。0.50 cycles/pixelの終点成分を最後の帯に含め、最後のビン中心表示が0.505になることがある。

## 解釈と今後
小標本の群中央値・代表窓の違いは記述的な観察であり、格子との位置や混入が検出成否の原因だと断定しない。LOIO最大値は近接窓を多数走査した結果であり、窓を独立サンプルとみなさない。大きいSは検出を保証せず、異常度の絶対値と他画像から決めた閾値の関係を併せて見る。
K=4で得意・不得意な傷の傾向は各表と図から仮説として確認し、対象窓と参照窓の混入、格子方向を保持した特徴、異なる検査画像での閾値安定性を事前に決めた条件で比較する。現在のデータだけで自動参照選択や傷の物理的原因を確定しない。
