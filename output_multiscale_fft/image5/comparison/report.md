# 局所FFT窓サイズ比較
画像: image5.png（2048×1536 px）

## 条件
窓: [64, 128, 192, 256] px、stride 16 px、参照3×3（中央除外、最大8）、間隔 128 px、周波数 0.02–0.5 cycles/pixel。平滑化・マスク除外なし。
周波数分解能（cycles/pixel）: 64: 0.015625, 128: 0.007812, 192: 0.005208, 256: 0.003906
比較図は全窓に共通の中心座標範囲。正規化図は窓ごとに共通範囲の (値−中央値)/標準偏差。色の上限は各図の99パーセンタイル最大値であり、傷の判定閾値ではない。
正常表面は未ラベル領域を仮定し、窓がいずれかのアノテーションに重なる場合は除外。中心・重なりの各傷評価は正常窓とは別に計算。

## 結果
- 64 px: 全域中央値 6.227 dB、95% 8.346 dB、最大 13.830 dB (1008, 112)、正常中央値 6.137 dB、正常標準偏差 0.319 dB。解析 3.4 秒。
- 128 px: 全域中央値 6.149 dB、95% 7.470 dB、最大 10.555 dB (848, 688)、正常中央値 6.072 dB、正常標準偏差 0.176 dB。解析 10.8 秒。
- 192 px: 全域中央値 6.115 dB、95% 7.101 dB、最大 9.903 dB (1104, 192)、正常中央値 6.044 dB、正常標準偏差 0.155 dB。解析 21.8 秒。
- 256 px: 全域中央値 6.048 dB、95% 6.805 dB、最大 9.465 dB (1072, 320)、正常中央値 5.995 dB、正常標準偏差 0.149 dB。解析 38.6 秒。

## 局所変形

- 64 px / overlap: 窓数 110、中央値 6.116、95% 6.722、最大 7.218 dB (1328, 704)、S=-0.066。
- 128 px / center: 窓数 42、中央値 6.079、95% 6.225、最大 6.329 dB (1328, 704)、S=0.038。
- 128 px / overlap: 窓数 210、中央値 6.025、95% 6.226、最大 6.499 dB (1392, 784)、S=-0.268。
- 192 px / center: 窓数 42、中央値 6.043、95% 6.123、最大 6.165 dB (1280, 768)、S=-0.008。
- 192 px / overlap: 窓数 342、中央値 6.003、95% 6.165、最大 6.373 dB (1408, 800)、S=-0.264。
- 256 px / center: 窓数 42、中央値 5.999、95% 6.048、最大 6.078 dB (1280, 752)、S=0.026。
- 256 px / overlap: 窓数 506、中央値 5.964、95% 6.066、最大 6.237 dB (1408, 800)、S=-0.208。
中心基準のS最大は 64 px（0.065）。1画像・1箇所であり、汎化性能やサイズ別の最適条件は判断できない。

## 考察と今後
窓サイズごとに正常標準偏差と傷領域の中央値・上位値・最大位置を参照。正常標準偏差には撮影条件や領域の違いも含まれ、スペクトル自体の安定性を単独で証明しない。局所変形が1箇所の場合、大きさ別の優劣は判断できない。
参照間隔128 pxに対し192・256 pxでは対象窓と隣接参照窓が重複し、同じ変形が双方に入ると差が弱まる可能性がある。周波数刻みも窓ごとに変わるため、窓サイズだけでなく評価周波数ビンも変わる。
複数画像・複数の大きさの変形で再評価し、中心と重なりの結果を併せて確認してからマルチスケール統合を検討する。
最大メモリはWindowsのプロセス生涯ピーク作業セットで、窓ごとにリセットされない。画像読込・図保存を除き、解析時間には特徴抽出、周辺比較、memmap作成・削除を含む。
