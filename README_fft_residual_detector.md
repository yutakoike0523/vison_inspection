# 正常輝点を除外する低周波FFT検出器

`fft_residual_detector.py` は、正常格子の輝点を無視し、残った低周波パワーの
合計がしきい値を超えた画像を「異常候補」とする試作プログラムです。
OpenCV / NumPy / Matplotlib を使用します。

## 指定した4点をマスクして計測する

`Figure_1.png` の表示寸法1128×1431と指定点付近のピークは、
`image15_triming.png` のFFTと整合します。以下は指定座標を**図全体の画素座標ではなく、
右側のFFT配列上の x, y（0始まり）**と解釈した実行例です。

```powershell
python fft_residual_detector.py measure --image 15 --triming --peaks 560,709 570,711 559,720 568,722 --radius-bins 2 --dc-bins 2 --low 0.025 --output outputs/fft_detector/image15_manual --show
```

指定4点と共役対称位置の周辺を、FFT配列上の半径2ビンで除外します。
点の位置は再検出せず固定します。半径は `--radius-bins`、積分帯の上限は `--low` で変更できます。
中心の半径2ビンも除外します。対称位置を追加するため、点指定が対称位置から少しずれている場合は
それぞれの円の和集合をマスクします。

この実行例のスコアは **120.9737723（8ビット輝度の二乗）**です。
正常・傷の判定しきい値はまだ未校正で、`anomaly_candidate` は `null` です。
残差には未マスクの格子高調波や照明むらも含まれ、傷だけの量ではありません。

同じ条件で決めたしきい値を `--threshold 値` として追加すると自動判定します。
または `--calibration normal_01.png normal_02.png normal_03.png` を追加すると、
別の正常画像（検査画像と同じサイズ）からしきい値を校正できます。
`--threshold` と `--calibration` は同時に指定できません。

出力には `diagnostic.png`、`result.json`、固定マスク入り `model.npz` とその設定 `model.json` が含まれます。
モデルは正常画像全体の認定ではなく、ユーザー指定の輝点だけを正常成分とみなしたものです。
保存モデルを別の同サイズ・同撮影条件の画像にも適用できます:

```powershell
python fft_residual_detector.py predict other_same_size.png --model outputs/fft_detector/image15_manual/model.npz --output outputs/fft_detector/other --show
```

未校正モデルを読み込んだ場合も、判定はせずスコアのみ出力します。
合成データ例のしきい値を、この実画像の判定に転用しないでください。

## 正常画像から自動で輝点を学習する処理

1. 窓の重み付き平均を引き、2次元ハン窓を掛けてFFTします。
   重み付き平均を使うため、窓を掛けた後のDCもほぼゼロになります。
2. 正常画像群の平均パワーから局所ピークを検出し、ピークと対称位置を円形にマスクします。
   X字の線全体を消すのではなく、正常画像にある輝点の周辺だけを除外します。
3. 中心のDC近傍を除いた低周波の円環内で、マスク外のパワーを積分します。
4. マスク作成に使わなかった正常画像群でしきい値を校正します。
   初期式は `校正スコア最大値 × 1.10` です。10%は調整用の仮の余裕で、統計的保証はありません。
5. 検査画像に固定マスクを適用し、`score > threshold` なら異常候補と判定します。
   しきい値以下は「この条件で検出しなかった」という意味です。

数式（W: ハン窓、N: 画素数）:

```text
mu = sum(I * W) / sum(W)
F  = fftshift(fft2((I - mu) * W))
P  = abs(F)**2 / (N * sum(W**2))
score = sum(P[低周波円環 AND NOT 正常輝点マスク])
```

表示には `log(1 + P)` を使用しますが、判定には線形のパワーを使用します。
対数画像の明るさの合計と、このスコアは異なります。
パワーの正規化により、合計は窓で重み付けした輝度変動量に対応します。
画像ごとの最大値では正規化しないため、傷で増えたエネルギーを保持します。

## コマンド

同じ縦横サイズ・倍率・向き・露光条件の正常画像を用意します。
下記の `normal_*.png` は実在する正常画像のパスに置き換えてください。
校正用は別の正常画像を最低3枚、実用評価では多様な正常条件を含む十分な枚数が必要です。
同じファイルを別名で複製して枚数を増やしても校正にはなりません。

```powershell
python fft_residual_detector.py fit --normal normal_01.png normal_02.png --calibration normal_03.png normal_04.png normal_05.png
```

モデルは `outputs/fft_detector/model.npz`、設定・校正スコアは `model.json`、
マスク確認図は `model.png` に保存されます。
まず確認図で正常輝点が適切に覆われていることを確認してください。
検査画像からマスクを学び直すことはありません。

```powershell
# モデルと同じサイズのトリミング済みimage2を検査
python fft_residual_detector.py predict --image 2 --triming --show

# 任意の切り出し画像を検査
python fft_residual_detector.py predict scratch.png --show

# 256x256の正常画像でモデルを作った場合、検査画像内の同サイズ領域を指定
python fft_residual_detector.py predict --image 2 --triming --roi 100 200 256 256 --show

# 保存先を分ける
python fft_residual_detector.py predict scratch.png --output outputs/fft_detector/scratch_01
```

`--roi` は左上を原点とした `x y 幅 高さ`、右端・下端は含まない範囲です。
画像サイズがモデルと違う場合はエラーになります。自動リサイズはしません。
全画像を走査する処理ではなく、指定画像または1つのROI全体の判定です。
マスク作成と検査の両方で、平均値減算・ハン窓は常にonです。
`predict` は `result.json` と6面の `diagnostic.png` を保存し、
`--show` を付けると図を画面にも表示します。再実行すると同じ保存先を更新します。

## 調整値（fit時に指定）

| 引数 | 初期値 | 内容 |
|---|---:|---|
| `--low` | 0.08 | 積分する低周波帯の上限 [cycles/pixel] |
| `--dc` | 0.005 | 中心の除外半径。最低でも短辺方向の2周波数ビン分 |
| `--peak-radius` | 0.004 | 輝点の除外半径。最低でも短辺方向の2周波数ビン分 |
| `--peak-relative` | 0.01 | 正常ピーク検出の下限（探索帯最大パワーに対する比率） |
| `--peak-prominence` | 4 | 周辺15x15ビンの平均に対するピークの最小比率 |
| `--margin` | 0.1 | 校正最大スコアに加える余裕の割合 |

積分帯は対象模様・傷の幅に合わせて決めます。ここでの初期値は汎用的な仮設定です。
パラメータを変更したら再度fitして、マスクとしきい値を一緒に更新してください。

## 評価の範囲と限界

- 正常基準の確認が必要です。image2やその特定ブロックを自動で正常とみなしていません。
- 照明むら、格子の回転・周期変化、ぼけもスコアを増やします。
  明るさの一様な加算は平均値減算で除けますが、露光ゲイン変化は除けません。
- 正常輝点と同じ周波数に重なる傷や、低周波帯外の傷は見逃す可能性があります。
- ハン窓で画像端の傷は弱まります。傷候補が端にある場合は切り出し位置を変えて評価してください。
- 欠陥のない画像と既知の傷画像を別の評価群として用意し、誤検出・見逃しを確認してください。
  本プログラム単体では傷種の特定や実データでの検出精度を保証しません。

数値検証:

```powershell
python -m unittest test_fft_residual_detector -v
```

合成格子への線状傷の追加、DC除去、パワー正規化、マスク対称性などを確認します。
`outputs/fft_residual_demo` にある場合、その画像・モデルは合成データの動作例です。
実画像用モデルとしては使用しないでください。
