# 格子間隔とFFT窓サイズが異常度RMSへ与える影響

## 目的

格子ライト画像に対し、格子周期と局所FFT窓サイズの関係を、周辺8参照との差分RMSヒートマップで確認した。格子点および領域アノテーションは結果の診断にだけ用い、FFT・参照選択・RMS計算には使用していない。

## 格子周期

Labelmeの3×3格子点 `grid01_r0_c0` などから、横方向6本の隣接距離中央値を `p_u`、縦方向6本の中央値を `p_v` とした。代表周期は `p=sqrt(p_u×p_v)` である。周期はimage2〜18の17画像で取得でき、約33.8〜198.8 pxと画像ごとに大きく異なった。image6は格子点1点欠損、image11・13はラベル表記ゆれを含むため記録した上で扱った。

詳細は `../grid_period/image_grid_summary.csv` と `../grid_period/grid_periods.csv` にある。

## RMS異常度の定義

窓サイズは32、64、128、256、512 px、ターゲット走査ストライドは16 pxである。各ブロックに平均値除去、2次元Hann窓、rFFT2、パワー計算、全帯域パワー正規化、放射方向ビン平均、`10 log10` 変換を実施した。使用帯域は0.01〜0.50 cycles/pixelである。

ターゲット中心から `±W` の8近傍（上下左右・斜め）を参照とし、8個すべてが画像内に存在する位置だけを有効とした。参照8本の周波数別平均を `R(f)`、ターゲットを `T(f)` として、スコアは `sqrt(mean((T(f)-R(f))²))` と定義した。端部は補間せずNaNである。

## 有効地点数と計算量

| 窓サイズ | 有効地点数の中央値 | 画像あたり処理時間の中央値 |
| ---: | ---: | ---: |
| 32 px | 11,193 | 0.65 s |
| 64 px | 9,945 | 0.79 s |
| 128 px | 7,665 | 2.02 s |
| 256 px | 3,969 | 5.82 s |
| 512 px | 33 | 16.06 s |

image18は128 px以上では8参照を置けないため未評価である。512 pxは他画像も有効地点が非常に少なく、局所ヒートマップとしての空間分解能は失われる。

## W/pでの比較

`W/p` は窓内の代表格子周期数である。32・64 pxでは、格子周期が大きい画像で窓内周期数が1未満となりやすい。256・512 pxでは複数周期を含むが、局所変形と表面境界が同じ窓に混ざりやすい。画像別W/pは `../fft_window/window_period_count_plot.png`、正常面RMSとの関係は `../normal_surface/grid_period_vs_rms.png` にある。

この関係は撮影条件、格子間隔、background、tag、傷を同時に含む記述的な比較であり、因果関係ではない。

## 解釈と次の候補

- 32・64 px: 有効地点が多く細かな変化を見せるが、格子周期の一部しか含まない条件では模様・照明ムラにも反応しやすい。
- 128・256 px: 局所性と周波数安定性の折衷候補。まずこの2条件を同一画像の共通スケール図で比較する。
- 512 px: 有効地点が少なく局所傷の位置情報が失われやすいため、対照条件として扱う。

最終選定では、傷中心、正常表面、background、tagの領域別分布を同一規則で比較し、別画像でも再現するかを確認する必要がある。
