# 放射方向平均FFT：全画像評価

## 条件
256×256 px、stride 16、参照3×3中央除外、参照間隔128 px、0.01〜0.50 cycles/pixel、半径幅0.01。元コードと同じ片側FFTパワー総和で正規化し、左右対称重み1または2を使った線形パワーの放射平均をdB化し周辺中央値との差をRMS集計。成分数4未満のビンは除外。前処理と式はimage5実験と共通。
最低参照数 3。正常窓は全アノテーションと非重複。正常点100未満または標準偏差1e-06未満のSは評価不能。未ラベルを正常とみなす仮定を含む。
共通閾値は各評価画像を除いた同じグループの正常窓から、画像ごとに合計重みが等しい経験分布の99%点として計算。各fold内では単一の閾値を使用し、fold間は変わる。参照側のラベルは正常窓を選ぶために使用し、評価画像自身のラベルを閾値設定に使用しない。正常99%点およびLOIOの境界は未知画像に事前固定された1個の閾値ではない。格子あり・なしは独立に学習・集計。傷インスタンス検出は該当窓の1つ以上が閾値超の場合。重なった窓を独立した傷として数えない。
image5はパラメータ選択に使われたため完全な独立評価ではない。他画像も同一データ収集の可能性があり、結果を一般化するには別データで検証が必要。

## 考察
Sは検出率ではなく正常分布との中央値差を標準偏差で割った値。S、画像内99%超、LOIOの窓超過率と傷単位の検出を併せて解釈する。256 px窓と128 px離れた参照は重なるため、対象と基準の双方に変形が入る可能性がある。未ラベルの傷、撮像条件、札に近い参照窓、欠陥の位置・サイズは結果に影響し得るが、ここでは原因を個別に検証していない。
傷の画素面積と長辺をインスタンスCSVに記録。傷が少なく画像や傷の条件も揃っていないため、大きさと性能の因果関係は断定できない。代表スペクトルの最大差周波数はインスタンスCSVに保存し、各代表点のスペクトル図と併せて確認する。
放射平均は方向情報を失うが、方向情報を使う方法や格子点位置の直接計測との比較は行っていないため、欠点や改善効果は実証されていない。画像間のばらつきが大きい場合は現条件の一般化を留保し、低周波成分と方向情報・格子点の位置ずれを独立画像で比較する。マルチスケールは今回の固定条件とは別実験で検証する。
