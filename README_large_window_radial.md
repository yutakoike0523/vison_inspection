# 大きいFFT窓と正常表面の比較

```powershell
python large_window_radial_experiment.py

# 保存済みFFTを再利用して再集計
python large_window_radial_experiment.py --summary-only
```

格子ライトありのimage2〜17について、256・320・384 px、stride 16、周辺3×3、周波数0.01〜0.50 cycles/pixel、放射ビン幅0.01を固定します。参照間隔128・384 pxを同じFFT特徴量で比較します。384 px間隔では全窓サイズで判定窓と参照窓が重なりませんが、比較対象の位置も変化します。

比較は384 px窓の共通中心座標範囲で、両参照間隔のどちらも最低3参照を持つ地点に限定します。正常評価は384 px窓が全アノテーションと重ならない座標を選び、その同じ座標を全窓サイズで使用します。未ラベルを正常と仮定します。閾値は評価画像を除いた学習画像の正常点を画像均等重みで統合した99パーセンタイルです。閾値はfold間で異なります。

既存の256 px解析が入力・パラメータともに一致する場合は再利用します。結果は `output_large_window_radial` に保存し、完了済み窓は再実行時に飛ばします。集計結果は既存の集計を上書きせず、別のsummaryフォルダーを作成します。image13とimage15の代表変形点は、中心点のうち異常度最大の地点を選ぶため、典型的な点や独立検証とは限りません。
