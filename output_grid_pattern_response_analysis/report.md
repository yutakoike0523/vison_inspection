# image14 / image17: 正常格子がFFT異常度に現れる原因分析

## 1. 目的
W=128 px、stride=16 px、中心間隔=128 pxの既存 Strict-B8 RMS マップを変更せず、image14とimage17で正常格子の応答が異なる要因を切り分けた。

## 2. 現在の異常度計算
各128×128 px窓を平均値除去・Hann窓後にrFFT2し、0.01–0.50 cycles/pixelの正規化logパワーを放射平均して1D化する。8近傍（中心から±128 px）の平均スペクトルとの差のRMSを異常度とする。8参照が全て画像内にある地点のみ有効。

## 3. 正常窓の定義
傷・tag・backgroundを含むアノテーション（格子pointを除く）と128×128窓が1 pxでも重なるターゲットを除外した。主表では、さらに8個の参照窓も全てannotation非重複の地点だけを使った。既存RMS値の再計算は行っておらず、後者は「既存スコアを汚染のない参照配置に限定して読む」解析である。アノテーションを16 px膨張した感度分析もCSVに記録した。

## 6. image14とimage17の違いの解釈
W/pが近いことは「窓に入る周期数」が近いことだけを示す。格子のピーク強度、線幅、ぼけ、窓内の位相、遠近・照明による局所変化までは拘束しない。さらにimage17は大きなtag領域を持つため、ターゲット自体が正常でも8参照の一部がtag/backgroundに重なる地点がある。`05_reference_annotation_effect.png`は、この参照汚染が既存RMSを押し上げる量を直接示す。従って当初のimage17の非常に高い上位値を正常格子だけの反応と解釈してはいけない。8参照まで正常な地点に限定した主表と、位相・局所領域・代表FFTを併せて格子そのものの寄与を判断する。

## 7. 改善案（アルゴリズム変更前の次の評価）
1. 位相依存が強ければ、参照を物理的近傍だけでなく同一格子位相の窓から選ぶ比較実験を行う。2. 領域依存が強ければ、局所的な格子基底・局所周期で正規化する。3. スペクトルピーク差が主因なら、格子ピーク周辺を除外/低重み化する案を、傷の検出低下とセットで評価する。これらは原因分析後の比較候補であり、今回の既存RMSは変更していない。
