# 0.02–0.05 cycles/pixel 帯域RMSヒートマップ

局所FFTの周囲参照差スコアではなく、各128×128px窓の帯域限定逆FFT画像のRMSを16px格子へ割り当てた結果である。ピーク探索は平均除去＋Hann、復元ノッチは非Hannの複素FFTに半径2 binのhard notchを適用した。`none` と `base` は同じ窓座標・同じ浮動小数点処理で比較した。

高調波・混合成分は、直前の固定条件では採用数0であった。そのため本実験は主目的どおり `none` と基本波のみの `base` の比較である。

## 1. 格子除去によるヒートマップの変化

- image15 は、帯域RMSマップの変化が小さい。基本波は約0.0055 cycles/pixel（周期182.9/175.5 px）であり、0.02–0.05帯域の外側にあるためである。
- image18 は、`base − none` がほぼ全域で負となり、格子由来の帯域成分が大きく抑制された。基本波は約0.029–0.030 cycles/pixel（周期33.3/34.8 px）で、評価帯域の内部にある。

## 2. 数値結果

|画像|条件|clean RMS平均|傷RMS平均|傷/clean比|解釈|
|---|---:|---:|---:|---:|---|
|image15|none|3.177|4.150|1.306|基準|
|image15|base|3.163|4.140|1.309|傷・正常ともほぼ不変|
|image18|none|4.134|4.315|1.044|格子成分が支配的|
|image18|base|0.808|1.061|1.313|双方は低下するが、正常面の低下がより大きい|

image18のclean RMSは約80.5%低下し、傷RMSは約75.4%低下した。したがって傷の帯域特徴の一部も除去されており、「傷を保存したまま格子だけを完全に除去できた」とは言えない。一方で比は 1.044 から 1.313 へ上昇したため、この固定帯域に限れば傷と正常の相対的な分離は良くなった。

## 3. 質問への回答

1. 格子除去後、image15のRMSヒートマップはほぼ変化せず、image18では全域的に低下した。
2. 正常格子領域のRMSはimage15で僅少、image18で大幅に低下した。
3. 傷領域もimage18で大幅に低下した。これは傷の成分を一部失った可能性を示す。
4. 傷/clean比はimage15でほぼ同じ、image18で上昇した。ただしRMS比だけでは検出性能を結論づけない。
5. 傾向は異なる。基本波が帯域外のimage15と、帯域内のimage18の違いと整合する。
6. 基本波が評価帯域内に入るほど、ノッチは帯域RMSそのものを強く下げる。帯域外なら直接影響は小さいが、高調波・漏れは別途監査が必要である。
7. image18では傷RMSも75%程度低下しており、弱い傷が消失する危険がある。画像と差分マップを併読する必要がある。
8. 帯域RMSを検出へ使うには、背景・タグを除外した評価、傷別の頑健性確認、帯域内に基本波がある画像への別処理、さらに固定閾値での性能評価が課題となる。

## 4. 検証上の注意

復元は `removed_base + grid_removed_base = original` を最大絶対誤差 `2e-13` 以下で満たした。ヒートマップは窓中心座標に対応する粗い格子であり、画像端の未評価部は補間していない。表示上のマップの連続性は `imshow` のセル表示によるもので、測定値自体を補間したものではない。
