# 元画像全体のFFT：中央拡大・DCマスク・対称ピーク候補

128・256画素のブロックごとに特徴量と異常度を比較する追加実験は、[局所FFTブロック実験](README_local_fft_block_experiment.md) を参照してください。

既存の `compare_fft_preprocessing.py` と同じ入力・出力指定方式の追加スクリプトです。他のローカルスクリプトに依存せず、単独で実行できます。

```powershell
python -m pip install numpy matplotlib opencv-python
python compare_fft_center_peaks.py
```

既定では `data20260903/data20260903` 直下の元画像をファイル名順に処理し、`outputs/fft_center_peaks` に保存します。png, jpg, jpeg, bmp, tif, tiff（大文字も可）に対応し、サブフォルダは検索しません。元画像はグレースケール化し、リサイズ・トリミングなしで全画素を使用します。複数ページTIFFは先頭画像を読み込みます。失敗した画像は記録し、他の画像を処理します。

## 処理と出力

浮動小数点化 → 全体平均を引く → 縦横Hann窓の外積を掛ける → `fft2` → `fftshift` → `log1p(abs(F))` の順に処理します。窓を掛けた後の平均値再除去や振幅補正は行いません。

各 `元ファイル名_fft_center_comparison.png` は2行×3列です。

| | 左 | 中 | 右 |
|---|---|---|---|
| 上 | 元画像 | Hann適用後のFFT全体 | FFT中央拡大 |
| 下 | 中央拡大＋DCマスク | マスク後＋ピーク候補 | ペア座標・周期・設定 |

FFT全体の黄色枠は表示用の拡大範囲です。元画像を切り出して再計算しているわけではありません。中央拡大は中心から既定で±150ビン（通常300×300画素）、DCマスクは中心から半径10ビンの円です。画像が小さい場合は有効な範囲だけを使います。マスクが全範囲を覆う場合は候補0件になります。

FFT全体は全体の1～99.8パーセンタイル、中央拡大はDC円外の1～99.8パーセンタイルで表示します。3枚の中央拡大図は共通スケールです。DCマスクは可視化用コピーを表示下限にするだけで、複素FFTや元のlog振幅を変更しません。スケール外の値は表示上だけ飽和します。

- `元ファイル名_peaks.json`: 画像サイズ、設定、実際の切り出し範囲、候補座標・距離・角度・log振幅・ペア番号。
- `statistics.csv`: 画像単位の設定と検出数。0件の画像も含みます。
- `peaks.csv`: 1候補1行の詳細。周期と周波数も保存します。
- `report.json`: 全画像の情報とエラー記録。
- `focus_images_peaks.png`: image7, image8, image11, image12, image18 の候補一覧。

## 設定変更

```powershell
python compare_fft_center_peaks.py --input-dir "画像フォルダ" --output-dir "保存フォルダ" --zoom-radius 150 --dc-mask-radius 10 --max-peaks 20
```

スクリプト先頭の `ZOOM_RADIUS`、`DC_MASK_RADIUS`、`MAX_PEAKS` でも変更できます。例えば中央をさらに拡大して確認するなら `--zoom-radius 80`、DC円を小さくするなら `--dc-mask-radius 5` とします。

候補の設定は `--peak-percentile 99`、`--min-peak-distance 7` です。7×7近傍の局所最大値のうち、DC円外のlog振幅の99パーセンタイル以上を候補にし、振幅の大きい順に最大20点（10組）を採用します。近い候補は間引きます。99パーセンタイルは相対的なしきい値であり、有意性の判定ではありません。

実数入力の共役対称性に基づき、対になるビンも中央拡大内で条件を満たす場合にペア採用します。同じ番号のA/Bが1組で、片方が表示範囲外の候補は採用しません。DCをゼロにした境界に偽の極大を作らないよう、局所最大の比較にはマスク前の近傍値を使い、候補の採用対象からDC円内を除きます。表示用クリッピング後の値は検出に使いません。

## 読み方

- **なぜ中央拡大するか**：数十画素程度の周期は低周波側に現れ、全体表示ではピークが数画素に縮小されます。FFT中央を拡大すると位置・広がり・対称性を確認しやすくなります。FFT自体の周波数分解能は変わりません。
- **なぜDC近傍をマスクするか**：残ったDCや緩やかな明るさ変動に目や候補選択が引っ張られにくくするためです。円内の本当の長周期成分も隠すので、マスクなしの図も併記します。特にサイズの小さい画像では同じ半径10でも隠す周波数帯が広くなります。
- **対称ピークと格子周期の関係**：実数画像の周期成分は正負の周波数に対となって現れます。格子では異なる方向の基本周期や高調波に対応する複数組が見えることがあります。ただし、ノイズやテープの境界も対称性を持つため、対称であることだけで格子由来とは断定できません。

オフセットはFFTのビン単位で、xは右向き、yは下向き、`angle_deg` は `atan2(y, x)` の度数です。長方形画像ではxとyの1ビンあたりの周波数幅が違うため、周期は単なる半径の逆数ではなく `1 / hypot(dx / width, dy / height)` [元画像の画素]で求めます。`frequency_angle_deg` はこの補正をした周波数方向で、縞の向きとは直交します。

本処理は目視検証用です。候補の検出数だけでは、傷検出の可否やトリミング省略の可否は判定しません。
