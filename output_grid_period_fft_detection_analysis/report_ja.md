# 局所FFTによる傷検出：格子周期・周波数帯域・窓サイズの影響

## 結論

今回の新規主実験（格子画像17枚、W=128、stride=16、周囲8窓の中心距離48 px）では、**元画像・正規化あり・0.01–0.05 cycles/pixel** が低FPRで最良だった。傷単位TPR@FPR 1%は **20/31=64.5%**、実測正常FPRは0.83%、PR-AUCは0.0311だった。

全帯域0.01–0.50では、元画像4/31（12.9%）に対して基本周期除去13/31（41.9%）、高調波込み14/31（45.2%）となり、格子除去が有効だった。一方、0.01–0.05だけでは元画像20/31、基本周期除去12/31、高調波込み11/31であり、**低周波の格子変形自体が傷情報を持つ場合には、格子除去が検出性能を下げる**ことが確認された。

したがって最終目標に対する第一候補は、格子を画像から消してから検出する方式ではなく、**元画像の正規化放射FFTを使い、0.01–0.05帯域を主スコアとする方式**である。全帯域の基本周期除去スコアを補助特徴として併用する余地はあるが、今回の結果を見てから組合せた方式なので、独立画像で再検証する必要がある。

## 1. 既存実装の監査

### W=128新規実験で維持した処理

1. 128×128 px窓から平均輝度を引く。
2. 2次元Hann窓を適用する。
3. rFFT2を行い、`power=|F|²`を計算する。
4. 正規化ありでは、2次元パワーを同じ窓の0.01–0.50 cycles/pixel内総パワーで除算する。
5. 共役側の寄与を重み付けして半径0.01幅で放射平均し、`10log10`へ変換する。
6. 対象中心から48 px離れた8方向の参照窓について、周波数ごとの**算術平均**を取る。
7. 対象dBスペクトルと参照平均dBスペクトルとの差のRMSをスコアにする。

正規化式は

`Pn(fx,fy) = P(fx,fy) / Σ P(fx,fy),  0.01 ≤ sqrt(fx²+fy²) ≤ 0.50`

である。低周波を基準に割る方式ではなく、帯域内総パワーによる除算である。dB領域では、窓ごとに総強度に対応する同じ定数を全周波数から引くことに等しい。したがって、スペクトルの絶対レベル差を弱め、形状差を残す。

参照位置は `(±48,±48), (0,±48), (±48,0)` pxで、必ず8窓すべてが画像内にある中心だけを評価した。傷・正常判定には対象中心16×16 pxを使用した。tag/backgroundとの重なりは除外した。

### 既存結果との条件差

- `analysis_fft_normalization_128.py`: W128だが距離128 px、帯域0.02–0.50、参照中央値。今回とは異なる。
- `output_window_size_vs_defect_size`: W64/128/192/256、距離128 px。窓サイズの補助証拠として使用した。
- `output_strict_b8_window_maps`: W64/128/256/512、参照距離=W。周期適応窓の探索評価に使用した。
- `analysis_fft_notch_spectral_mechanism`: 固定座標の除去前後スペクトルを確認する補助証拠として使用した。

条件の異なる結果は、W128・距離48の主実験と数値を直接混合していない。

## 2. 格子周期

局所512 px窓の基本ピークを、傷・tag・backgroundと重ならない窓から集計した。正常窓が得られない場合だけ全窓へフォールバックした。

- 推定周期は約33.5～229 px。
- W128に含まれる周期数は約0.56～3.82周期。
- 17画像中9画像をhigh、8画像をmedium confidenceとした。
- image13・15は周期CVが約0.44～0.52、image16は約7.42で、局所ピークの切替えや低周波分解能の影響が大きく、単一周期として不安定だった。
- image5・10・13～17などはW128に長い側の周期が1周期未満しか入らない。W128で基本周波数を安定表現するには不足している。

`T=1/|g|`は格子線の法線方向周期であり、格子線に沿った間隔ではない。詳細は `grid_period_summary.csv` にg1/g2、IQR、CV、prominence、各窓内周期数を保存した。

## 3. 周波数帯域・格子除去・正規化

### 主要結果

|画像条件|正規化|帯域/方式|ROC-AUC|PR-AUC|傷単位TPR@1%|傷単位TPR@5%|実測正常FPR@1%|
|---|---|---|---:|---:|---:|---:|---:|
|元画像|あり|0.01–0.50|0.6519|0.0227|4/31 (12.9%)|17/31 (54.8%)|1.14%|
|元画像|なし|0.01–0.50|0.6742|0.0222|1/31 (3.2%)|16/31 (51.6%)|0.73%|
|基本周期除去|あり|0.01–0.50|0.6722|0.0303|13/31 (41.9%)|27/31 (87.1%)|0.87%|
|高調波込み|あり|0.01–0.50|0.6548|0.0302|14/31 (45.2%)|25/31 (80.6%)|0.81%|
|元画像|あり|0.01–0.05|0.6693|0.0311|20/31 (64.5%)|28/31 (90.3%)|0.83%|
|元画像|あり|0.02–0.10|0.6343|0.0298|13/31 (41.9%)|25/31 (80.6%)|0.46%|
|元画像|あり|0.05–0.50|0.6237|0.0210|4/31 (12.9%)|15/31 (48.4%)|1.13%|
|元画像|あり|放射格子周波数除外|0.6413|0.0218|4/31 (12.9%)|15/31 (48.4%)|1.13%|
|元画像|あり|2D格子ベクトル除外|0.6320|0.0213|4/31 (12.9%)|16/31 (51.6%)|1.14%|

閾値は評価画像自身を除外した同群正常窓の画像等重み分位点である。FPR 1%と5%で画像単位LOIOを実施した。31傷は中心16×16 pxの評価候補を持つ傷であり、窓全体が傷へ重なる方式とは別である。

### 帯域境界とビン数

帯域は左閉右開、最終0.50だけ終点を含めた。W128の使用放射ビン数は、0.01–0.50が49、0.02–0.50が48、0.02–0.10が8、0.01–0.05が4、0.05–0.50が45である。帯域を切り出した後の再正規化はしていない。

0.01–0.05は4ビンだけなので周波数位置の解釈は粗いが、低FPR傷単位検出では明確に優位だった。0.05以上だけにすると性能が低下したため、今回の傷情報は高周波テクスチャだけでなく、格子の低周波変形・陰影変化に強く含まれている。

## 4. なぜ格子除去後もヒートマップが似るのか

H1は概ね支持された。正常な格子は対象窓と近接8窓の両方に含まれるため、参照平均との差で共通成分が相殺される。格子を画像上で大きく弱めても、対象と参照が同程度に変われば差RMSは大きく変わらない。

全画像のマップ中央値では、高調波込み後の変化率中央値は正規化ありで−6.1%（17枚中13枚で低下）だったが、正規化なしでは+3.4%（低下は2枚）だった。画像の見た目ほどスコアが下がらないのは、検出器が格子の絶対強度ではなく、対象と参照の差を測るためである。

既存の固定窓スペクトル検証でも、ノッチ後に正常スコアの標準偏差が0.4406→0.4121、正常99%点が2.9227→2.6528へ低下する一方、傷候補中央値は2.1049→2.4372へ増加した。単純に全スペクトルが弱くなるのではなく、正常尾部と傷差の再配分が起きている。

## 5. 正規化の効果

全帯域の元画像ではROC-AUCだけを見ると正規化なしが高いが、傷単位TPR@1%は正規化あり12.9%、なし3.2%だった。正規化により照明強度、反射率、Hann後の総エネルギー差が除かれ、低FPR閾値を支配する正常窓の絶対レベルばらつきが弱くなる。その結果、傷によるスペクトル形状差が残りやすい。

ただし正規化は常に全指標を改善するわけではない。ROC順位と低FPR検出率は異なる目的であり、今回は実運用上重視する傷単位TPR@1%を優先した。

## 6. 放射帯域除外と2次元ベクトル除外

両方式は別に実装した。

- 放射除外: `|g1|, |g2|`と予測高調波の半径近傍を、放射平均後の1次元ビンから除外。
- 2D除外: rFFT平面上でg1/g2と整数結合ベクトルの半径1.5 FFT-bin近傍画素を除外してから放射平均。有効画素4点未満の放射ビンは使用しない。

元画像・正規化ありでは、傷単位TPR@1%はいずれも4/31で、全帯域をそのまま使う条件を改善しなかった。格子周波数だけを機械的に除くと、傷による格子変形情報も同時に失う可能性がある。

## 7. 窓サイズ

既存の距離128 px比較では、格子画像15傷に対する結果は次のとおりだった。

|W|分離度S中央値|LOIO検出傷|
|---:|---:|---:|
|64|0.484|3/15|
|128|1.117|2/15|
|192|1.942|3/15|
|256|2.666|4/15|

大きい窓ほど分離度中央値は上がったが、検出数の改善は小さい。W/Tが増えると格子周期表現は安定する一方、小傷が窓内で希釈され、参照との重複や有効範囲も変わる。

W≈4Tを使ったラベル非参照の画像単位適応では、16評価画像中14画像がW512、2画像がW256となった。固定W128は傷単位TPR@1%=1/29、PR-AUC=0.0196、適応方式は0/5、PR-AUC=0.0178だった。適応方式では評価可能傷が5件まで減り、実測FPRも1%目標に対して2.52%へ上昇した。したがって、**単純なW≈4T規則は128固定より有効とは確認できない**。

この適応比較は参照距離=Wの保存済みStrict-8マップを使用した。W128以外の距離48固定スイープは計算量のため今回再計算しておらず、距離固定時の純粋な窓効果とは断定しない。画像内領域適応も、異なるWのスコア校正を未実施のため採用しなかった。

## 8. 仮説への回答

1. **なぜ格子除去後もヒートマップがあまり変わらないか**：対象・参照の共通格子成分が差分で既に相殺され、総パワー正規化も絶対強度差を除くため。
2. **8窓差分で格子が相殺されるか**：概ね相殺される。ただし格子の局所変形は対象と参照で異なるため残り、それが傷信号にもなる。
3. **正規化で傷が見やすい理由**：窓ごとの総エネルギー差を除いて形状差を残し、正常分布上側のばらつきを抑えるため。低FPR検出率で効果が大きい。
4. **有効帯域**：今回のW128・距離48では0.01–0.05が最良。0.05–0.50だけでは低下した。
5. **周期と最適窓の関係**：W128に1周期未満の画像が多く、大窓でSは増える傾向があるが、傷検出率との単調な関係は弱い。
6. **格子を除去しない方がよい条件**：存在する。0.01–0.05では元画像20/31、基本波除去12/31、高調波込み11/31だった。
7. **周期適応窓は128固定より有効か**：W≈4Tの単純規則は不支持。W512偏重と評価可能領域減少が問題だった。
8. **最大の改善要因**：低FPR傷単位TPRでは帯域選択が最大（全帯域元画像12.9%→低帯域64.5%、+51.6ポイント）。次が全帯域での格子除去（+29.0～32.3ポイント）。正規化の効果は+9.7ポイント。窓拡大は既存条件で2/15→4/15にとどまった。

## 9. 推奨構成

現時点の共通構成候補は次のとおり。

1. 元画像を使用する。
2. W128、stride16、距離48 px、周囲8窓算術平均。
3. 0.01–0.50総パワー正規化。
4. 主スコアは0.01–0.05の放射スペクトル差RMS。
5. 補助スコアとして、基本周期除去後の0.01–0.50正規化RMSを検討する。
6. 閾値は画像別最適化せず、同条件の学習正常画像から画像等重みで設定する。

主スコアと補助スコアの統合方法・閾値は今回のデータで選ばず、外側の画像単位交差検証または独立画像で決定する。低帯域4ビンへの依存が撮像条件変更でも維持されるかも確認する。

## 11. 制約

- 窓は大きく重複しており、窓数を独立標本数とはみなさない。
- 31傷は中心16×16評価候補が存在する傷で、全アノテーション数と一致しない場合がある。
- image18は小さく、保存済みStrict-8 W128マップがないため適応窓比較から除外した。
- image13・15・16の周期は局所ばらつきが大きく、単一Tによる選択は不安定。
- 周波数帯域と処理構成を今回の画像群で比較・選択したため、報告値は独立な最終汎化性能ではない。
- W64/128/192/256の傷評価は距離128 px、W64/128/256/512の適応評価は距離=Wであり、W128・距離48の主実験と条件が異なる。
