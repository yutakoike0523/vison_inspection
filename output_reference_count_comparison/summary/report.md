# 参照数と画像端の比較

既存放射FFT特徴量を再利用し、image1〜21を解析。窓256 px・stride16・参照間隔128 px。D方式は全有効候補のスペクトル間RMS距離から平均距離最小のmedoidを選び、同点は左上から右下の固定順、medoidから近い順に最大K個を選んで周波数別中央値を取る。K=1はmedoid単独。候補数Mが3以上の地点だけを全K共通で評価し、実使用数=min(K,M)。対象と参照は完全に画像内にある窓のみで、パディングは使用しない。

全有効地点と、8候補が利用可能な地点を別評価。LOIOの閾値はK・領域・照明グループ別に、評価画像以外の正常窓の画像均等重み99%点として求める。正常窓は全アノテーションと重ならない窓。傷中心に1点以上の超過があるインスタンスを検出とし、8候補領域に傷中心がない場合は未評価として分母から除外する。無格子1,19,20,21は別のLOIO。image18は小画像の参考集計で、独立群の閾値は作らない。

前回の5参照LOIOの共通領域とは異なり、今回は全有効と8候補の2領域で閾値を再計算している。Kはこの実験で比較しているため、最大検出のKを選んだ成績は独立した最終評価ではない。各FFT窓は重複する。

## 画像端の検証
image15 (896,224) は候補5、image17 (656,336) は候補8。各候補数Mの地点でK>=Mの全結果が一致すること、全Kで候補3以上の同じ地点が有効なことをassertで確認。image15の最上端 y=128 の対象窓も画像内に収まり、対応する参照が3個以上あれば計算する。

## 注意
K=8は有効候補全数の中央値と一致する。medoid近傍のKと、ランダムKや任意のKは異なる。K=1対K>1の比較は中央値と選択数の影響を見るが、各Kで選ばれる集合も変わるため、それぞれの因果効果を完全には分離しない。正常誤検出率は窓単位であり、実製品の画像単位誤検出率ではない。画像ごとに参照数を最適化した結果や自動選択の性能は測定していない。
全地点の候補数・K別異常度・選択方向・画像端距離は各locations.npzに保存。selected_bits_kNのbit 0〜7は左上、上、右上、左、右、左下、下、右下に対応。中心座標に方向×128 pxを加えると選択参照座標を復元できる。
処理時間は既存FFT特徴量の読込後を対象とする。距離・medoid・並べ替えは全Kで共用し、total_if_separate_secondsは各Kを単独実行した場合の構成要素の合算である。
