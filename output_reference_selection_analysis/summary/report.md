# 参照選択の検証

既存の放射FFT特徴量を再利用。image2〜17、256 px、stride16、間隔128、周辺3×3、0.01〜0.50 cycles/pixel、ビン0.01。56組合せはimage17の従来法における傷中心最大点での探索結果。上側除外・背景低5・一貫性5の比較は参照位置と数が同時に変化し、因果分離を保証しない。

A=利用可能な最大8個、B=上側3候補を除外、C=背景占有率の低い最大5個（正解ラベル使用、診断専用）、D=周辺参照間のRMS距離の平均が最小のmedoidとその最近傍4個。Dは対象スペクトルと正解ラベルを使わない。候補5個未満では全候補を使用、3個未満は無効。距離・背景の同値は左上から右下の固定順に選択。類似した多数派が正常とは限らず、距離が大きくても強制選択するため安全な自動フォールバック閾値は検証していない。

対象窓が全ラベルと重ならない点を正常と仮定。共通領域はA〜Dがすべて有効な座標。傷中心・正常領域とも同一画像・同一方式のS、画像内正常99%点を計算。正常誤検出率には画像内正常99%点超と、LOIO閾値超を区別して使用。

Cは評価画像の正解ラベルを使う探索診断のみ。LOIOにはA・B・Dを固定し、他の画像の正常点を画像均等重みとした99%点を方式ごとに算出した。評価画像ラベルは閾値と参照選択には使用せず、評価と共通有効座標の定義には使用する。Dの規則は事前固定であるが、今回2画像を調べた後の探索であり、独立した外部検証ではない。image5は既存条件選択に使われている。

## 限界・次の検証
参照数を固定しても組合せにより代表点のRMSが変われば、単に8個という数だけでは説明できない。一方、背景・傷・参照同士の距離は互いに関連し、56組合せは独立ではないため、どれが主因かは確定できない。背景なしと類似スペクトルの一致は代表点のselected_references.csvを比較する。Bは上側を除く固定規則であり画像全体に一般化できる保証はない。
今回の結果からラベルなしのDが正常格子を見つけたと断定できない。参照同士の多数派にも傷が混入する。採用する方式やフォールバックは別の画像で事前に決め、独立データで確認する。計算時間はFFT特徴量読み込み後の選択・中央値・RMSの測定を含む。selection_median_score_secondsはA〜D合計であり、D単独の追加時間ではない。
