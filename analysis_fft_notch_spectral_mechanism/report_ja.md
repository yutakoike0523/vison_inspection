# 格子ノッチで局所FFT検出が変化した理由

## 結論

- 同一の窓中心・同一の8参照窓で比較した結果、ROC-AUCは **0.6843 → 0.6908**、FPR 1% TPRは **0.0361 → 0.0722**、FPR 5% TPRは **0.1878 → 0.2261**で再現した。
- 正常windowスコアの標準偏差は **0.4406 → 0.4121**、99%閾値は **2.9227 → 2.6528**。正常同士のばらつきが小さくなったかは、この二つの値と帯域別CSVで判断する。
- 0.02–0.05 cycles/pixelの正常–参照RMS中央値は **1.3597 → 1.4312**。傷個体の同帯域RMS変化と総スコア変化の相関は **r=-0.524**であり、低周波帯だけで全ての性能変化を説明できるかを過大解釈してはならない。
- 全帯域をまとめた正常スコアの標準偏差と99%点は低下した一方、最下帯域 0.02–0.05 の正常RMS中央値は上昇した。仮説Aは「全帯域・特に正常スコアの上側の尾部について支持、全帯域一様な低下としては不支持」である。
- 固定した傷候補窓では傷スコア中央値が **2.1049 → 2.4372**、29傷中22傷（75.9%）でスコアが増えた。0.02–0.05帯域の傷–参照RMS中央値は **3.0889 → 3.1986** と小幅に増えたが、負の相関 r=-0.524 より、個別傷の改善はこの帯域だけではなく0.10–0.50帯域の差の再配分も含む。仮説Bは「傷差が平均的には増す」が、主要因を低帯域だけとする解釈は不支持である。
- image15では、除去したピーク近傍だけを逆FFTした成分のRMSは格子ポイント領域で **40.03**、注釈を除く全有効域で **19.06** だった。二つの格子軸の成分RMSは **20.76**, **20.28**。これはピークをゼロ化したという事実とは独立に、画像上で実際に大きな周期明暗を取り去っていることを示す。
- 仮説A（正常ばらつき低下）と仮説B（傷差増大）は、`normal_window_*` と `defect_*` を並べて評価した。低FPR改善は、正常スコアの尾部・傷スコアの双方の変化で起こり得るため、片方だけを根拠にしない。
- 以前の `grid_modulation_reduction_pct` は20px高域残差の標準偏差で、約180pxの格子以外の粒状成分にも強く反応した。本解析では選択ピーク近傍を逆FFTした空間成分そのものを `image15_grid_component_spatial_validation.png` とCSVで示す。
