# 局所変形サイズとFFT窓サイズの比較

## 目的・方法
同一の局所変形インスタンスを64・128・192・256 pxで比較し、サイズ依存性を検討する。窓以外はstride 16 px、3×3参照（中央を除く最大8、最低3）、間隔128 px、0.01〜0.50 cycles/pixel、半径ビン幅0.01で固定。元コードの片側FFT範囲総パワー正規化、共役重み付き線形放射平均、dB化、参照中央値とRMSを使用。
正常領域は窓全体が全アノテーションと非重複、未ラベル領域を正常と仮定。中心と重なりを別評価する。正常窓100未満、正常標準偏差1e-6未満、傷の評価窓4未満はSを評価不能とした。4窓共通の画像中心座標範囲での結果を主とし、各窓の全範囲もCSVに保存。
LOIOは評価画像を除いた同グループ正常窓の画像均等重み付き99%点をfoldごとに決める。各foldでは一つの閾値だが、fold間で変わる。検出は傷中心窓の1点以上が閾値を超えることと定義。窓の重なりによる検出は札等に反応する可能性があり、別に扱う。
窓ごとに周波数分解能と有効ビンが異なる。64 pxは1/64=0.015625 cycles/pixelで、0.01未満・一部のビンは観測できず補間しない。frequency_bins.csvに周波数ビン・個数を保存。192・256 px窓は128 px離れた参照と重なる。
image1・19〜21の格子なし画像は別集計、image18は小画像として条件別に扱い、主解析・LOIO閾値学習には含めない。image5は条件選択に使っており完全な独立検証ではない。

## 観測された窓サイズの違い
傷ごとの事後的な最大Sの窓数: {64: 0, 128: 1, 192: 3, 256: 11}。固定窓のLOIO中心検出数: {64: 3, 128: 2, 192: 3, 256: 4}。4条件のいずれかで閾値超となる傷は 5 件（OR統合の誤検出率は未校正）。
異なる窓が最大Sとなること自体はマルチスケールの検討材料だが、傷ごとの事後選択は未知画像の検出率ではない。傷の大きさだけで窓を決める規則や、単調なサイズ依存をこれだけで確定できない。
結論：傷の大きさに合わせて窓を変更する規則は、現時点では採用しない。研究の次候補はB（複数窓の統合）とし、256 px単独を基準に比較する。ただしOR統合の誤検出率は未校正であり、Bの実用上の優位性は未実証。

## 追加実験：参照間隔
192・256 px窓のうち同データでLOIO検出数が多かった 256 pxを探索的に選び、参照間隔128・192・256 pxを比較。既存のFFT特徴量を再利用し、周辺中央値とスコアだけ再計算。条件選択自体は独立検証ではない。
- 間隔 128 px: S中央値 2.666、LOIO中心検出 4/15。
- 間隔 192 px: S中央値 1.942、LOIO中心検出 2/15。
- 間隔 256 px: S中央値 2.366、LOIO中心検出 1/15。
参照間隔を広げると重複だけでなく参照する画像位置と有効な窓数も変わるため、差を重複だけの因果効果とは解釈できない。

## 計算時間・メモリ
処理時間は画像読込・描画・保存を含まない解析時間。256 pxは既存の同条件結果を再利用した場合がある（CSVのorigin列）。ワーカー数4、batch 64。メモリはWindowsプロセス生涯のピーク作業セットで、同一プロセスで窓を順番に実行した場合は各窓独立のピークではない。

## 解釈・今後
最大Sの窓は評価対象の正解ラベルを見て選んだ事後的な結果で、未知画像で使える固定設定の性能ではない。傷ごとの4窓は繰り返し観測であり、単純な独立標本とした有意性検定は行わない。傷数は少なく、傷の大きさ・場所・形状・照明は交絡する。中心窓や参照窓が札と重なる可能性、参照窓との重複、窓ごとの周波数分解能の違いも結果に影響しうる。
固定スケールのLOIO結果と、傷ごとの事後的な最大Sのばらつきを比較し、マルチスケール統合を検討する。未知画像の傷サイズを使わず、訓練画像だけから各窓スコアを標準化し、最大値などの統合と閾値を訓練データ内で決定したうえで、画像単位の外側LOIOで評価する。統合後の誤検出と欠陥検出を別途検証する必要がある。
