# FFTによる格子模様の位相・振幅解析

`phase_anomaly_detection.py` は、グレースケール画像の周期成分を直接取り出す独立した実験です。格子点や白円の中心、連結成分、理想格子点の配置は使いません。既存スクリプトは変更していません。

image15での実測結果と考察は [output_phase_analysis/README.md](output_phase_analysis/README.md)、全体の比較画像は [summary.png](output_phase_analysis/09_anomaly_score/summary.png) にあります。今回の基本設定では、2方向の周期成分は取り出せましたが、既存の傷候補R171を周辺から明確に区別する結果にはなっていません。

## 実行

このフォルダを作業ディレクトリにして実行します。

```powershell
python -m pip install -r requirements_phase_analysis.txt
python phase_anomaly_detection.py
python -m unittest test_phase_anomaly_detection -v
python review_phase_anomaly_detection.py
```

入力は既存の比較実験と同じ `data20260903/data20260903/triming/image15_triming.png`（幅1128×高さ1431 px）を自動探索します。見つからなければ `image15.png` を探し、同名が複数ある場合は明示指定を求めます。macOSの `._` メタデータや `outputs` 以下の画像は選びません。

このトリミング画像は紙や大きな背景部分が切り落とされており、初回解析では追加のROIマスクを使っていません。傷候補R171との比較座標も、この入力画像の座標です。未トリミング元画像への座標変換は推定していません。

```powershell
# 手動ピーク：fftshift後のDCからの符号付きオフセット (dx, dy)
python phase_anomaly_detection.py --peak1 -5 5 --peak2 4 6 --output output_phase_manual

# 帯域幅は周波数側の標準偏差、平滑化sigmaは画像上の画素数
python phase_anomaly_detection.py --band-sigma 3 --phase-sigma 60 --amplitude-sigma 60 --output output_phase_wide

# 別画像、長方形ROI。終端x1,y1は含めない
python phase_anomaly_detection.py --image data20260903/data20260903/image15.png --roi 100 120 1100 1400 --output output_phase_roi

# 必要なら、入力画像と同サイズの物体領域マスクを明示指定
# python phase_anomaly_detection.py --image IMAGE.png --roi-mask MATERIAL_MASK.png --output output_phase_masked
```

`--roi-mask` は白を対象、黒を対象外とする補助的な物体領域マスクです。格子を明度で二値化したマスクを与える用途ではありません。画像の大きさと同じである必要があり、ROI切り出し前の座標で指定します。輪郭の内側32 pxを滑らかに弱めて、境界の周波数漏れを抑えます。

同じ `--output` に実行すると、この実験が生成する同名ファイルを更新します。異なる条件を比較するときは出力先を分けてください。

## 処理の意味

### FFTで模様を「方向と周期」に分ける

画像の明暗が一定間隔で繰り返されると、FFTにはその繰り返しに対応する強い成分が現れます。画像上の各円を探す代わりに、この成分をまとめて取り出します。DCは平均的な明るさに対応する中心です。中心から遠いほど細かい繰り返しになります。

周波数ベクトルの角度は「その方向へ進むと明暗が繰り返す向き」です。復元される縞の線自体とは直交します。長方形画像では横・縦のFFTの1 binの大きさが異なるので、角度・周期・フィルタ形状は `fx=dx/width`, `fy=dy/height` の cycles/pixel で計算します。

1. グレースケール化し、対象範囲の平均輝度を引く。
2. 縦横のHann窓を掛け、画像端を滑らかに暗くする。
3. `fftshift(fft2(image))` を計算する。
4. DC付近を除外し、周波数範囲内の局所最大を強い順に最大30個記録する。
5. 対称位置の強度を確認し、2方向の角度差が35°以上になる組を選ぶ。強度の幾何平均×角度差のsinで組を評価する。

対称ピークは実数画像のFFTで一般に生じます。対称性だけでは格子の証拠にはなりません。また高調波や別の模様を基本周期と誤認する可能性もあるため、候補一覧、復元画像、手動指定を用意しています。

### 片側ピークから振幅と位相を取り出す

対称な両側を同時に残すと、逆FFTはほぼ実数になり、角度が主に0/πとなって連続的な位相を扱えません。ここでは各方向の**片側だけ**を残し、複素数画像 `C` を作ります。

- **振幅 `A=abs(C)`**：その場所で繰り返し模様がどれくらい強く見えるか。暗い／明るいの絶対値ではなく、周期成分の強さです。
- **位相 `phi=angle(C)`**：繰り返しの途中のどこにいるか。波の山が横にずれると位相が変わります。円の中心座標を求める必要はありません。

フィルタはGaussian型です。DC、反対側のピーク、もう一方の方向に重ならない範囲まで支持領域を制限し、外周20%をcosineで滑らかにゼロへ落とします。

`--band-sigma 2` は、画像の短辺を基準とした等価FFT binでの標準偏差です。実際には `sigma_frequency=2/min(height,width)` cycles/pixel。支持半径は、3σ・DCまでの90%・他の±ピークまでの距離の48%・Nyquistまでの余裕の最小値です。設定値と実際の支持半径は両方ともレポートに残します。狭くすると滑らかになりますが小さい傷が薄まります。広げても、ピーク間隔による上限があるため際限なく細部を取り戻せません。

### Hann窓と振幅の補正

Hann窓はFFTの境界漏れを抑えますが、窓そのものが画像端の振幅を下げます。そこで、生の `A1/A2` に加えて、同じ帯域に対応する低域フィルタでHann窓を平滑化した包絡で割った振幅を保存します。異常評価にはこの補正振幅を使います。片側成分なので、入力が振幅30のcos波なら `abs(C)` は約15です。復元画像だけは `2*real(C)` を表示します。

窓が小さい場所を割り算で過剰に持ち上げないよう、元の窓と補正包絡がともに0.15以上の場所だけを評価します。この条件による**評価対象外は正常判定ではありません**。

### 位相を連続にして、ゆっくりした変形を引く

`angle` は−π〜πで折り返すため、そのまま差を取ると模様の各周期に偽の段差が出ます。選択ピークの規則的な進み方 `2π(fx*x+fy*y)` をいったん引いた位相に、2次元 `skimage.restoration.unwrap_phase` を適用します。低振幅の場所はマスクし、乱数シードを固定します。保存するアンラップ後の位相には規則的な進み方を戻しています。

位相から最小二乗の一次面を引き、信頼できる画素を重みとしたGaussian平滑化で背景を求め、一次面を戻します。直線的な位相進行を画像端で丸めて偽の異常を作るのを抑えるためです。その後、`residual=unwrapped-smooth` とします。一次面の計算は画素を間引きますが、FFTとスコアは入力解像度のままです。

考え方は次の通りです。

- 正常な曲面：模様の位置がゆっくり変わる → 位相もゆっくり変わる → 平滑な背景として引く。
- 傷・凹み：模様の位置が局所的に変わる → 背景で説明できない位相残差の候補になる。
- 擦り傷・反射：模様の強さが局所的に変わる → 振幅残差の候補になる。

これは原因の確定ではありません。急な曲率変化、照明、汚れ、位相の復元失敗でも反応します。深さを測るための校正もしていません。

### 3種類のスコア

```text
phase_score = sqrt(r1**2 + r2**2)                   # rad
amplitude_residual_i = abs(A_corrected_i - A_smooth_i)
relative_amplitude_residual_i = amplitude_residual_i / max(A_smooth_i, 0.2)
amplitude_score = sqrt(relative_residual_1**2 + relative_residual_2**2)
```

振幅の絶対差と相対差を両方保存します。相対差は模様の元々の濃さの影響を軽減しますが、非常に弱い模様では不安定になります。位相は補正振幅が各方向の中央値の15%以上、かつ0.2階調以上の場合だけ採用します。振幅異常自体を隠さないため、この振幅下限は振幅スコアには適用しません。

有効画素でスコアの中央値とMAD（中央値からの絶対偏差の中央値）を計算し、`z=max((score-median)/max(1.4826*MAD,1e-8),0)` とします。総合スコアは `0.5*phase_z + 0.5*amplitude_z`。重みは変更できます。両方向の位相が有効な場所だけ総合スコアを出します。

このzは画像内の相対的な目立ちやすさです。欠陥確率、検定の有意度、画像間で共通の合否基準ではありません。表示だけを0〜6で打ち切り、数値配列は打ち切りません。各オーバーレイの色と透明度は共通のzスケールを使います。

## 検証の範囲

人工画像の既知の2方向波形を使い、ピーク選択、片側帯域分離、位相折り返しとの整合、Hann補正、滑らかな曲面と局所位相乱れの区別、振幅低下への反応、奇数寸法、補助ROIの外側の独立性、不正入力を検証します。8テストは実画像の傷検出率を意味しません。

設定感度比較は帯域1.5/2/3、背景平滑化60/100/160 pxについて一度に一つずつ条件を変えた5条件です。R171と既存の8近傍領域は解析のパラメータ選択・ピーク選択には使わず、固定の比較領域としてだけ使用します。これらは画像を16×16に区切った矩形であり、検出した格子セルではありません。周辺領域も正常確認済みではありません。

位相アンラップの仕様は [scikit-image公式ドキュメント](https://scikit-image.org/docs/stable/api/skimage.restoration.html#skimage.restoration.unwrap_phase) を参照しました。
