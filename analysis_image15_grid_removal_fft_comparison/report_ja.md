# image15 格子除去前後の局所FFT比較

## 比較条件

- 解析窓: 128×128 px
- ストライド: 16 px
- 参照窓: 周囲8方向、中心間距離48 px、周波数ごとの算術平均
- 周波数帯域: 0.01–0.50 cycles/pixel
- 特徴量: 共役側を重み付けした放射平均log-powerスペクトル
- スコア: 対象窓と周囲8窓の平均スペクトルとの差のRMS
- 正規化あり: FFTパワーを窓ごとの帯域内総パワーで除算してから放射平均
- 正規化なし: 総パワー除算だけを省略し、ほかは同一

## 色スケール

提示された補助図と同じ `inferno` を使用した。表示下限・上限は、格子除去前画像の補助正常領域におけるp05–p99で固定した。正規化あり・なしは単位と分布が異なるため列ごとに色域を持つが、各列内では「格子除去なし」「local fundamentals」「fundamental + confirmed harmonics」の3条件に同一色域を適用した。

- 正規化あり: 0.670–2.813 dB
- 正規化なし: 0.718–2.802 dB

上限を超えるスコアは最高色、下限未満は最低色に飽和表示している。スコア値自体はクリップしていない。

## 全有効地点の結果

|スペクトル|条件|スコア中央値|スコアp99|補助正常領域中央値|補助正常領域p99|
|---|---|---:|---:|---:|---:|
|正規化あり|格子除去なし|1.0794|4.0612|1.0006|2.8132|
|正規化あり|local fundamentals|0.9959|3.5730|0.9305|2.4880|
|正規化あり|fundamental + confirmed harmonics|0.9783|3.5362|0.9182|2.4649|
|正規化なし|格子除去なし|1.1230|3.3376|1.0865|2.8017|
|正規化なし|local fundamentals|1.1181|3.3304|1.0882|2.7908|
|正規化なし|fundamental + confirmed harmonics|1.1159|3.3206|1.0855|2.7916|

正規化ありでは、格子除去なしに対して全有効地点の中央値が `local fundamentals` で約7.7%、高調波込みで約9.4%低下した。正規化なしの中央値低下はそれぞれ約0.4%、約0.6%である。したがって、この条件では格子除去による「周囲とのスペクトル形状差」の低下が正規化あり側で明瞭に現れている。一方、正規化なし側の局所RMSは大きく変わっていない。

このRMSは対象窓と参照窓の差であり、FFT総パワーそのものではない。正規化なし側は絶対レベル差を保持するが、「格子成分の総エネルギーが何%減ったか」を直接表す指標ではない。

## 出力

- `image15_normalised_unnormalised_shared_normal_scale.png`: 4行×2列の比較図
- `score_summary.csv`: 条件別のスコア要約と表示色域
- `image15_score_maps.npz`: 6種類のスコアマップ、座標、正常領域マスク
- `settings.json`: 再現条件
