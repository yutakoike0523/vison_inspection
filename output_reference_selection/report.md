# 参照配置・正常参照の探索実験

image15・17の全画像、256 px窓、stride 16 px、参照間隔128 px。既存の放射平均スペクトルを使用。代表点は従来8参照方式で傷中心の異常度が最大の点。FFT処理・RMS式は不変。周辺配置は境界で欠ける参照を除き最低3点とする。正常スコアも同じ方法で算出し、窓が全ラベルと重ならない地点を正常とした。

local_clean8はラベルを含まない窓から、対象窓と重ならない最も近い8窓。distant_clean8は傷の外接矩形から512 px以上離れたラベルなし窓を256 px以上離して走査順に最大32点選び、そのうち対象窓と重ならない先頭8点。対象ごとに候補を除外するため完全固定テンプレートではない。両手法は評価画像の正解ラベルを参照に使用する探索的な上限分析で、未知画像で実行可能な方法の性能ではない。傷から離れた場所でも参照同士や周辺参照と画像構造が異なる可能性がある。

既存8参照方式のLOIO閾値は他の方法では較正されていないため、超過の有無は参考値に限る。方法ごとの学習画像を使ったLOIO閾値・独立評価は実施していない。図の各マップは個別の色範囲であり、表示色は判定閾値ではない。

## 限界
正常ラベルのない部分を正常と仮定。ラベルで参照から異常を除外できるという前提を用いており、推論時には同じ情報を利用できない。Sと異常度は同一画像内で計算した記述統計で、参照配置・参照数・距離・窓の重なりは同時に変化する。これらだけから検出性能の因果関係や未知画像の性能を断定できない。周波数別寄与と参照座標は各CSV、スペクトルは各PNGに保存。
