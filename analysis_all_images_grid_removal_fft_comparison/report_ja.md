# 全格子画像の格子除去前後・局所FFT比較

## 対象と条件

格子模様があり、局所格子ノッチ用の事前ピークが定義されている `image2`～`image18` の17枚を処理した。格子なし群の `image1・19・20・21` は対象外とした。

- 解析窓: 128×128 px
- ストライド: 16 px
- 参照窓: 周囲8方向、中心間距離48 px、周波数ごとの算術平均
- 周波数帯域: 0.01–0.50 cycles/pixel
- スコア: 対象窓と周囲8窓の平均放射スペクトルとの差のRMS
- 比較条件: 格子除去なし、`local fundamentals`、`fundamental + confirmed harmonics`
- 左列: ヒートマップ重畳前の画像
- 中央列: 帯域内総パワー正規化あり
- 右列: 正規化なし
- 行順: 元画像、基本周期除去、基本周期＋確認済み高調波除去

色域は画像ごと、かつ正規化あり・なしの列ごとに、格子除去前画像の補助正常領域p05–p99から決めた。同じ画像・同じ列の3条件には同一色域を適用している。

## 全画像の傾向

高調波込みと格子除去なしを、全有効地点のスコア中央値で比較した。

- 正規化あり: 17枚中13枚で低下。画像ごとの変化率中央値は **−6.1%**、範囲は −19.5%～+18.9%。
- 正規化なし: 17枚中2枚で低下。画像ごとの変化率中央値は **+3.4%**、範囲は −0.6%～+14.1%。

正規化ありでは、多くの画像で格子除去後に「周囲とのスペクトル形状差」が小さくなった。一方、`image7・8・11・18`では高調波込み後の中央値が増加した。したがって、格子除去がすべての画像・場所で異常スコアを下げるわけではない。

正規化なしでは、多くの画像で中央値がわずかに増えた。ノッチ後の絶対スペクトルレベル変化や、対象窓と参照窓で除去量が異なる影響が残るためと考えられる。ただし、このRMSはFFT総パワーそのものではなく、対象と参照のlogスペクトル差である。

`image18`は428×321 pxと小さく、補助正常領域は91地点だけである。他画像の正常地点数は4,103～8,658地点なので、image18の色域と変化率は特に不安定であり、同列に強く比較しない。

## 高調波確認条件

既存の全画像格子除去実験を再現した。`image15`は512/256/128 pxのマルチスケール確認、その他の画像は512 pxスケールでprominenceを確認している。この違いがあるため、image15以外も厳密に同じ3スケール条件へ変更した比較ではない。

## 出力

- `per_image/`: 各画像の3行×3列比較図（日本語ラベル）
- `all_images_score_summary.csv`: 全画像・全条件の色域とスコア集計
- `image*_score_maps.npz`: 生スコアマップ、座標、正常領域マスク
- `settings.json`: 再現条件
