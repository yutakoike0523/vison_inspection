# 画像全体 2次元 FFT：格子ピークと逆 FFT の確認

## 結論

- **格子ライトに対応する有力な成分は、FFT中心の周囲にある、ほぼ直交する二つの共役ピーク対**であった。全画像で「最強ピーク対」と「それと約90°異なる次ピーク対」を残すと、二方向の縞が重なった格子／市松状パターンが復元された。
- **1組だけ**では一方向の正弦状縞しか復元されない。一方で、**上位3組**では image2、image13、image15、image16 等で元画像と同じ向きの格子が明瞭に再現される。上位5組・10組は格子の形を多少補うが、照明むら、画像境界、札の縁などの非格子成分も混入する。
- 特に分かりやすい例は **image15** である。上位2ピーク対は `(fx, fy)=(-0.004395, 0.003255)` と `(0.003418, 0.004557)` cycles/pixel（周期 **182.85 px**, **175.54 px**）で、周波数方向は **143.47°**, **53.13°** とほぼ直交する。上位3組の逆FFTに二方向格子がはっきり現れる。
- 格子ピークの周期は画像間で一定ではなかった。image2〜17の最強ピーク対の周期は **57.88〜195.76 px**（中央値 **132.05 px**）、特に明瞭な低周波の格子例 image13/15/16 は **175.54〜195.76 px**であり、従来の約178 pxという見立てと整合する例がある。ただし、全画像へ178 pxを固定値として適用する根拠はない。

## 実施条件

- 主対象: `image2`〜`image18`。指定どおり格子なしの `image1`, `image19`, `image20`, `image21` は除外した。
- 入力は画像全体をグレースケール化し、画像平均との差し引き後に2次元FFTを実施した。
- 窓なしと2次元Hann窓ありを両方作成した。ピーク探索では中心から半径4 FFT-bin以下だけを除外した。これはDCとごく近傍を除きつつ、低周波の格子候補を残すためである。
- 局所最大（5×5近傍）を抽出し、実数画像で必ず現れる中心対称の係数を1組に統合した。CSVの `fx`, `fy` の単位は cycles/pixel、`period_px = 1 / sqrt(fx^2 + fy^2)` である。
- 逆FFTは、選んだピークとその中心対称ピークの**元の複素係数**を保持して実施した。従って位相を捨てていない。各ピークの周囲は半径0, 1, 2, 3 FFT-binを比較し、主比較図には半径2を採用した。

## 画像で読む結果

各 `per_image/*_none_overview.png` は、左上から順に元画像、パワースペクトル、上位20共役ピーク対、上位1/3/5/10組、格子候補群の逆FFTを並べている。逆FFTはグレースケールと、ゼロ中心の青赤カラーマップ（符号付き）の両方である。

- `image15_none_overview.png`: 上位1組は斜めの縞だけ、上位3組で元の二方向格子が復元される。札の形や傷は再現されず、周期構造が主に残る。
- `image02_none_overview.png`: 上位3組で格子が復元される一方、札の周辺では弱くなる。格子が画像全体で完全な定常周期ではないことも読み取れる。
- `*_radius_comparison.png`: 半径0でも主格子は見えるが、半径1〜2で周辺に広がったスペクトルエネルギーを含められ、格子らしさが増す。半径3は背景成分も増えやすい。

Hann窓ありでは、端部不連続由来の十字状・広がった成分が抑えられる一方、窓により端部の振幅が小さくなる。その逆FFTは窓を掛けた信号の復元であり、端部でゼロに近い窓で割り戻す処理は不安定なので行っていない。格子の**ピーク位置の確認**にはHann結果を併用し、元画像との視覚的な再現確認には窓なしを主に用いるのが妥当である。

## 解釈と次段階

1. **どこにあったか**: 中心近傍（ただしDCの外側）の対角方向に、ほぼ直交する二つの共役ピーク対として現れた。FFT図の水色マーカーがその位置である。
2. **ピークだけで再現できたか**: 再現できたのは主として格子の向き・大まかな間隔・市松状の明暗である。札、傷、局所的な照明変動の細部はほぼ再現されず、これは限られた周期成分だけを残した期待どおりの結果である。
3. **必要な組数**: 1組では不足し、二方向を含む上位3組が実用上の最小に近い。5組以上は忠実度を少し上げる一方、非格子成分を増やすトレードオフがある。
4. **完全再現できない理由**: 実画像の格子は有限領域、照明強度の変動、物体／札による遮蔽、遠近やわずかな非一様性を含む。そのためエネルギーは単一binでなく周囲・高調波へ広がり、全画像FFTだけでは位置依存の周期変化を表せない。
5. **除去への含意**: 対称なノッチ（ピーク周辺を含む）でこれらを抑制すれば格子を弱められる可能性は高い。ただし、本結果は除去性能の評価ではない。上位5/10組が背景も復元していることから、固定ノッチをそのまま適用すると傷や輪郭を損ねる恐れがある。次段階では、Hann窓で確認した安定ピークに絞り、画像ごとの周波数ずれ・周辺半径・局所FFTを検証する必要がある。
