# 格子除去後の 0.02–0.05 cycles/pixel 局所逆FFT比較

## 方法
- ピーク探索: 平均除去＋2次元Hann窓。復元ノッチ: 非Hannの平均除去複素FFTにhard notch半径2 bin。
- 基本波は周期25–250 px、突出度4 dB以上、方向差60–120°の組から強度和最大の2組。
- 高調波／混合成分は予測位置2 bin以内・突出度4 dB以上・局所再現性（5窓以上かつ50%以上）を全て満たす場合のみ採用。
- 128px局所処理は平均除去＋Hann、0.02–0.05 cycles/pixelのみを位相保持で逆FFTした。全条件で窓座標と共通発散スケールを固定。
