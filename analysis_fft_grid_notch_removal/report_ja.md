# FFT格子ピーク除去の検証

## 結論

- image15では、前回確認した直交する上位2共役ピーク対を半径2 FFT-binでノッチすると、選択ピーク領域のパワーは **100.0%**低下した。上位1組では縞が残り、上位2組で二方向格子を抑えられる。画像15の格子ポイント周辺では平均絶対変化が **39.31**（全正常域 **14.61**）であり、空間画像でも大きな市松状の明暗が弱まる。
- 半径を広げると格子成分はより減るが、周辺の実画像成分も除去する。Gaussianノッチは急峻なゼロ化より穏やかだが、格子の残りも多い。image15の比較は傷ラベルを使わずに行い、全画像には固定の `top2 + hard radius 2` を適用した。
- 同一の既存局所FFT検出器（128px、stride 16px、strict-8、総パワー正規化）では、プールしたwindow ROC-AUCは **0.6843 → 0.6908**、FPR 1%のwindow TPRは **0.0361 → 0.0722**、FPR 5%では **0.1878 → 0.2261**。各条件の正常window数は92,951で、実測FPRは各々0.999%／4.999%（約929／4,647 window）で一致した。したがって、格子が視覚的に弱まっただけでなく、この評価器では小さいが一貫した低FPR側の改善も観測された。
- 傷インスタンス単位では、局所変形のFPR 1%検出率は **13.3% → 46.7%**、点状異常は **27.3% → 54.5%**、線状異常は **0% → 0%**だった（FPR 5%は順に86.7%→86.7%、90.9%→90.9%、66.7%→66.7%）。従って、この条件は全傷種に万能ではなく、線状異常への改善根拠はない。
- image15の傷領域の平均絶対変化は **17.88**、正常域は **14.61**であり、除去は傷にも作用する。しかし傷対周囲の平均コントラストは **6.40 → 6.90**、局所RMSはCSVで併記しており、この例で傷が一律に消えたとはいえない。
- ノッチの周波数は格子だけに専有されない。傷の局所コントラストとRMSもCSVで同時に測定しており、傷が残る／弱まる効果を分離して確認する必要がある。

## 出力の読み方

- `image15_selected_notch_overview.png`: 元画像、格子ピークのみ、除去結果、差分、FFT前後。
- `image15_peak_set_comparison_r2.png`: 除去するピーク組数の比較。
- `image15_notch_width_comparison.png`: hard r0〜r3 と Gaussian σ0.7/1.2/2.0。
- `image15_defect_roi_before_after.png`: 傷アノテーションの拡大。
- `per_image/`: image2〜18の固定条件の代表図。image18は小画像のため、検出器性能集計には含めない。

## 限界

全画像性能値は、image15でラベルを使わずに決めた固定条件を対象にした比較であるが、同じ画像群での探索的な評価であり完全な独立テストではない。次段階では画像単位のleave-one-image-outでノッチ幅やピーク組を固定して検証する必要がある。

## CSV

- `image15_notch_parameter_comparison.csv`: 全ピーク組・ノッチ幅の空間指標（傷指標も参考として併記）。
- `notch_removal_metrics_by_image.csv`: 画像ごとの格子抑制・傷／正常領域変化。使用したピーク座標は前回の `fft_peak_pairs_top20.csv` の同じ画像・`window=none`・`rank_all=1,2` 行であり、`per_image_conditions.csv` の `top2_pairs=2` と対応する。
- `local_fft_performance_summary.csv`: window単位のROC-AUC、FPR固定TPR、誤検出率。
- `local_fft_instance_scores.csv`: 傷インスタンス単位。
- `local_fft_performance_by_defect_type.csv`: 傷種類別。
